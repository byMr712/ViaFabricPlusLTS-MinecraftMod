Расширенный форк мода **ViaFabricPlus** для **Minecraft (Fabric)**, возвращающий игрокам на старых версиях клиента возможность подключаться к серверам вплоть до самых новых версий. Обозначение **LTS** (*Long-Term Support* — долгосрочная поддержка) в названии отражает главную цель форка: продлить жизнь оригинальному моду ViaFabricPlus на широком спектре старых версий Minecraft, позволяя комфортно оставаться на любимой сборке модов и свободно играть на любых серверах.

---

## Что делает этот мод? (Простыми словами)

Оригинальный проект [ViaFabricPlus](https://github.com/ViaVersion/ViaFabricPlus) от FlorianMichael и команды ViaVersion ориентирован прежде всего на поддержку самых актуальных версий Minecraft: с выходом каждого нового обновления игры фокус разработки переключается на свежие версии клиента.

Из-за этого игроки сталкиваются с дилеммой:
- Либо играть на любимой стабильной версии (например, 1.21.4, 1.21.1, 1.21 и др.) со своей тщательно настроенной сборкой модов, но потерять возможность заходить на новые сервера;
- Либо переходить на новую версию игры, теряя совместимость с большинством модов.

### Философия этого форка:
Этот проект меняет философию: **он дарит старым версиям Minecraft полноценное подключение к новейшим серверам**. Вы остаётесь на своей версии клиента со всеми модами и комфортно играете на любых серверах!

## Ключевые возможности и улучшения

- **Бэкпорт поддержки серверов до 26.3 / 1.21.11:** Включены актуальные библиотеки ViaVersion и ViaBackwards, позволяющие клиентам старых версий игры подключаться к серверам любых версий — от первой мультиплеерной Classic c0.0.15 до современных релизов и снапшотов.
- **Предпрогрев протоколов (Async Protocol Warmup):** Устраняет 30-секундный таймаут авторизации («ReadTimeoutException») при первом подключении к новым версиям. Маппинги загружаются асинхронно в фоне при наведении/выборе в меню или при пинге серверов.
- **Опция «Исправлять двойную трансляцию» (Fix Double Translation):** Включена по умолчанию в разделе настроек «Отладка Mr712». При подключении к серверам с установленными плагинами ViaVersion / ViaBackwards динамически опрашивает сервер и отключает ненужную клиентскую трансляцию, если сервер уже поддерживает нативную версию клиента. Это снижает нагрузку на процессор, устраняет задержки сети и ложные кики античитом, сохраняя при этом пользовательские настройки версии нетронутыми.
- **Защита декодера пакетов (Safe Netty Decoder):** Перехватывает повреждённые Brigadier-пакеты дерева команд (`CommandTreeS2CPacket`) и остаточные байты буфера, подставляя безопасный фоллбэк и предотвращая дисконнекты при несовместимости плагинов сервера.
- **Раздел настроек «Отладка Mr712»:** Отдельный раздел настроек в меню мода, содержащий расширенные параметры совместимости, переключатели режимов прогрева и опцию устранения двойной трансляции.

## Установка

1. Скачайте релиз мода под нужную вам версию игры (например, `MrViaFabricPlusLTS-1.21.4-byMr712.jar`) из раздела [Releases](https://github.com/byMr712/ViaFabricPlusLTS-MinecraftMod/releases).
2. Поместите `.jar` файл в папку `mods` вашего экземпляра Fabric.
3. Убедитесь, что установлен **Fabric Loader** (>=0.16.10) и **Fabric API** для вашей версии Minecraft.
4. Запустите игру — кнопка выбора версии появится на главном экране и в меню сетевой игры.

## Сборка из исходников

Для сборки мода:

```bash
git clone https://github.com/byMr712/ViaFabricPlusLTS-MinecraftMod.git
cd ViaFabricPlusLTS-MinecraftMod
./gradlew build
```

Собранный файл будет находиться в директории `build/libs/`.
