Расширенный форк мода **ViaFabricPlus** для **Minecraft 1.21.4 (Fabric)**, возвращающий возможность подключаться со старых версий клиента ко ВСЕМ серверам вплоть до самых новых версий (**1.21.11** и **26.3**), чего не делает официальный апстрим.

---

## Что делает этот мод? (Простыми словами)

Оригинальный [ViaFabricPlus](https://github.com/ViaVersion/ViaFabricPlus) от FlorianMichael и команды ViaVersion следует строгой политике: мод разрабатывается **только под самую последнюю версию Minecraft**, а поддержка старых версий клиента забрасывается сразу после выхода очередного обновления игры.

Из-за этого игроки сталкиваются с дилеммой:
- Либо играть на любимой стабильной версии (например, 1.21.4) со своей тщательно настроенной сборкой модов, но потерять возможность заходить на новые сервера;
- Либо переходить на новую версию игры, теряя совместимость с большинством модов.

### Философия этого форка:
Этот проект меняет философию: **он дарит старым версиям Minecraft полноценное подключение к новейшим серверам**. Вы остаётесь на своей версии клиента со всеми модами и комфортно играете на любых серверах!

## Ключевые возможности и улучшения

- **Бэкпорт поддержки серверов до 26.3 / 1.21.11:** Включены актуальные библиотеки ViaVersion и ViaBackwards, позволяющие клиенту 1.21.4 подключаться к серверам любых версий — от первой мультиплеерной Classic c0.0.15 до современных релизов и снапшотов.
- **Предпрогрев протоколов (Async Protocol Warmup):** Устраняет 30-секундный таймаут авторизации («ReadTimeoutException») при первом подключении к новым версиям. Маппинги загружаются асинхронно в фоне при наведении/выборе в меню или при пинге серверов.
- **Опция «Исправлять двойную трансляцию» (Fix Double Translation):** Включена по умолчанию в основных настройках мода. При подключении к серверам с установленными плагинами ViaVersion / ViaBackwards динамически опрашивает сервер и отключает ненужную клиентскую трансляцию, если сервер уже поддерживает нативную версию клиента. Это снижает нагрузку на процессор, устраняет задержки сети и ложные кики античитом, сохраняя при этом пользовательские настройки версии нетронутыми.
- **Защита декодера пакетов (Safe Netty Decoder):** Перехватывает повреждённые Brigadier-пакеты дерева команд (`CommandTreeS2CPacket`) и остаточные байты буфера, подставляя безопасный фоллбэк и предотвращая дисконнекты при несовместимости плагинов сервера.
- **Настройки для отладки Mr712:** Расширенные опции совместимости и переключатели режимов прогрева скрыты по умолчанию и включаются отдельной аккуратной опцией в меню мода.

## Установка

1. Скачайте последнюю версию мода `ViaFabricPlusLTS-1.21.4-byMr712.jar` из раздела [Releases](https://github.com/byMr712/ViaFabricPlusLTS-MinecraftMod/releases).
2. Поместите `.jar` файл в папку `mods` вашего экземпляра Fabric.
3. Убедитесь, что установлен **Fabric Loader** (>=0.16.10) и **Fabric API** для вашей версии Minecraft.
4. Запустите игру — кнопка выбора версии появится на главном экране и в меню сетевой игры.

---

## Сборка из исходников

Для сборки мода:

```bash
git clone https://github.com/byMr712/ViaFabricPlusLTS-MinecraftMod.git
cd ViaFabricPlusLTS-MinecraftMod
./gradlew build
```

Собранный файл будет находиться в директории `build/libs/`.
