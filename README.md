**ViaFabricPlusLTS** — расширенный долгосрочный (LTS) форк популярного мода [ViaFabricPlus](https://github.com/ViaVersion/ViaFabricPlus), поддерживаемый [byMr712](https://github.com/byMr712).
Данный форк адаптирован для **Minecraft 26.1** с полноценной поддержкой современных и старых сетевых протоколов.

---

### ✨ Особенности сборки LTS для 26.1

- 🌐 **Подключение ко всем версиям**: Подключайтесь с клиента Minecraft 26.1 к серверам от Classic c0.0.15 до современных версий.
- 📱 **Поддержка Bedrock**: Подключение к серверам Minecraft Bedrock Edition (до 1.26.30).
- 🛠 **Точные исправления физики и визуала**: Воссоздание оригинальной механики движения, блоков и сущностей соответствующих версий.
- ⚡ **Оптимизированная сборка**: Единый чистый JAR-архив без лишних артефактов (`ViaFabricPlusLTS-26.1-byMr712.jar`).

---

### 📦 Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) для **Minecraft 26.1**.
2. Установите [Fabric API](https://modrinth.com/mod/fabric-api) для 26.1.
3. Скачайте `ViaFabricPlusLTS-26.1-byMr712.jar` из раздела [Releases](https://github.com/byMr712/ViaFabricPlusLTS-MinecraftMod/releases) и поместите в папку `.minecraft/mods`.
4. Запустите игру и выберите версию протокола в меню мультиплеера.

---

### ⚠️ Важно знать

- **Только Fabric**: Мод предназначен только для загрузчика Fabric.
- **Только клиент**: Мод работает на стороне клиента в многопользовательском режиме.
- **Честная игра**: Поведение некоторых старых протоколов может вызывать подозрения серверных античитов. Используйте с умом.
